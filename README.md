# موقع أذكار الصباح والمساء 🌅🌙

موقع عربي أنيق لأذكار الصباح والمساء الصحيحة بمصادرها.

## المميزات
- ✅ جميع الأذكار صحيحة بمصادرها (البخاري، مسلم، أبو داود، الترمذي)
- 📿 مسبحة إلكترونية لكل ذكر مع حفظ التقدم
- 🔍 تبويبات: صباح / مساء / الكل + شريط تقدم
- 🔠 تكبير وتصغير الخط
- 🌙☀️ ثيم داكن / فاتح
- ✒️ خط ثمانية (IBM Plex Sans Arabic) + Amiri Quran للآيات

## النشر
الموقع منشور عبر GitHub Pages:
- ضع ملف `index.html` في جذر المستودع وفعّل Pages على فرع `main`

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح — لا يحتاج سيرفر.
